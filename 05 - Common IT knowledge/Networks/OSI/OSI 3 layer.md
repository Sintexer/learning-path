> AKA **Network layer**

This [[OSI Model]] layer is responsible for **logical addressing and routing** data packets across interconnected networks (from source host to destination host across multiple hops).

- **PDU**: Packet
- **Examples**: IPv4, IPv6, ICMP (`ping`/`traceroute`), BGP, OSPF, IPsec ([[VPN]]), routers, [[CIDR Notation]], [[Subnet]], [[Virtual Private Cloud|VPC]] route tables.

## Flashcards

OSI Layer 3:::Network layer — handles logical IP addressing and multi-hop packet routing across networks (IP, ICMP, BGP, routers, [[Subnet|subnets]]).

What is the difference between L2 switching and L3 routing?::L2 switches forward frames within a single [[LAN]]/[[VLAN]] using ==MAC addresses==; L3 routers forward packets across different networks/[[Subnet|subnets]] using ==IP addresses== and route tables.
