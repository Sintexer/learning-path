> AKA **Presentation layer**

This [[OSI Model]] layer is responsible for **data representation, serialization, compression, and encryption**. It ensures data sent by one system can be decoded and understood by another regardless of internal platform representation.

- **PDU**: Data
- **Examples**: [[Data Encoding]] (UTF-8, JSON, [[Protocol Buffers]], [[Apache Thrift]]), compression (gzip, Brotli, zstd), encryption ([[TLS]]).

## Flashcards

OSI Layer 6:::Presentation layer — translates, serializes, compresses, and encrypts data between network wire format and application format (e.g., [[TLS]], JSON, [[Protocol Buffers]], gzip).
