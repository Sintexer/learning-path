**ETL (Extract, Transform, Load)** is the automated pipeline used to move data from operational databases into an analytical data warehouse:

1. **Extract:** Pull raw data from multiple disparate sources (databases, logs, APIs).
2. **Transform:** Clean, standardize, and restructure the data for analysis (e.g., deduplicating, converting currencies, aggregating).
3. **Load:** Write the finalized data into a target data warehouse for querying and business intelligence.
